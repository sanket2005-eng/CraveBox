# 🍕 Pizza O Cafe - Indian Food Ordering Website

A premium Indian food delivery web application built with React, Tailwind CSS, and Framer Motion.

## 🚀 Features

### Indian Localization
- ✅ All prices in Indian Rupees (₹)
- ✅ Exact menu prices from Pizza O Cafe menu
- ✅ Indian address format (House No, Area, Landmark, PIN Code)
- ✅ Indian mobile number format (+91)
- ✅ GST calculation (5%)
- ✅ Gurgaon, Haryana location
- ✅ Indian phone number: 9933880173

### Menu Categories
- 🍕 **Pizza (Veg)** - 6 items
- 🍗 **Pizza (Non-Veg)** - 5 items
- ➕ **Extras** - 3 items
- 🍔 **Burgers (Veg)** - 5 items
- 🍗 **Burgers (Non-Veg)** - 5 items
- 🥟 **Momo** - 2 items
- 🥟 **Pan Fry Momo** - 2 items
- 🍝 **Pasta** - 2 items

### Payment Options
- 💵 Cash on Delivery
- 📱 UPI (Google Pay, PhonePe, Paytm, BHIM)
- 💳 Credit/Debit Cards

### UI/UX Features
- 🎨 Warm orange/red/yellow Indian gradients
- ✨ Smooth Framer Motion animations
- 🎯 Glassmorphism effects
- 📱 Fully responsive (mobile-first)
- 🛒 Animated add-to-cart interactions
- 🔥 Hot Deals & Combo Offers sections
- ⭐ Rating & prep time indicators
- 🟢🔴 Veg/Non-Veg indicators

## 📦 Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
